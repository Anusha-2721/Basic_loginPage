# Basic_loginPage
<ins>**Project Overview:**</ins>
This project is a frontend web application that provides user authentication pages and a post management page. It is designed with a simple and responsive user interface using HTML, CSS, and JavaScript.

<ins>**Key Features:**</ins>
User Registration page for creating a new account
User Login page for accessing the application
Form validation for user inputs
User-friendly and responsive design
Post page to display and manage posts
Simple navigation between pages
Clean UI with reusable styling
Frontend implementation using HTML, CSS, and JavaScript
Pages Description
<ins>**1. Login Page**</ins>
Allows existing users to enter their login details.
Contains input fields for username/email and password.
Provides a login button to submit user information.
Includes a link to the registration page for new users.
<ins>**2. Registration Page**</ins>
Allows new users to create an account.
Contains fields like name, email, password, and other required details.
Validates user input before submission.
Helps users register into the application.
<ins>**3. Post Page**</ins>
Displays posts created by users.
Allows users to view post content.
Provides an organized layout for showing posts.
Acts as the main page for post-related activities.
<ins>**Technologies Used**</ins>
HTML5
CSS3
JavaScript
**Project Purpose**
The main purpose of this project is to build a basic frontend application with user authentication UI and a post display system while improving web development skills.
